# Easy Comment

Easy Comment is a Chrome extension that helps you quickly generate and post comments on YouTube videos — using ready-made local templates or on-device AI (Gemini Nano), with no API key required for AI mode.

**Chrome Web Store:** [Easy Comment](https://chromewebstore.google.com/detail/easy-comment/nidncjnlippkfbjppakpbffogblcjjof)

**GitHub:** [RaziPour1993/EasyComment](https://github.com/RaziPour1993/EasyComment)

## Features

- **Star rating (1–5):** Choose how positive or negative the comment should feel
- **Local mode:** Instant comments from built-in templates for each rating
- **Gemini Nano (on-device AI):** Generate comments with Chrome’s built-in AI — no API key, matched to the video topic and title language
- **Preview & post:** Review the comment before sending it to YouTube
- **In-page button:** One-click AI comment next to the Subscribe button
- **About page:** Project info, GitHub link, and contact from the extension popup

## Requirements for Gemini Nano

- Desktop Chrome with Prompt API / Gemini Nano available
- If on-device AI is unavailable, use **Local** mode instead

## Installation

### From Chrome Web Store

Install from:  
https://chromewebstore.google.com/detail/easy-comment/nidncjnlippkfbjppakpbffogblcjjof

### From source (developer mode)

1. Clone the repository:
    ```bash
    git clone https://github.com/RaziPour1993/EasyComment.git
    ```
2. Open Chrome and go to `chrome://extensions/`
3. Enable **Developer mode**
4. Click **Load unpacked** and select the project folder

## Usage

1. Open a YouTube video page
2. Click the Easy Comment extension icon
3. Choose **Local** or **Gemini Nano**
4. Select a star rating (1–5)
5. Click **Generate Comment**
6. Use **Preview** or **Post Comment**
7. Or click the button next to **Subscribe** for a one-click AI comment
8. Open **About** in the popup for project links and contact
